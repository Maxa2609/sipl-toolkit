# Мова SIPL (версія 1.0 цього репозиторію)

Формальна граматика: `grammar/sipl.ebnf` (тест `test_grammar_file_matches_lexer` перевіряє, що її
термінали збігаються з лексером).

## Граматика
**За замовчуванням — рівно БНФ курсу** (практикум, практична робота 1; `grammar/sipl.ebnf`, частина 1):
`P ::= begin S end`; `S ::= x := a | S1; S2 | if b then S1 else S2 | while b do S | begin S end | skip`;
`a ::= n | x | a1 + a2 | a1 - a2 | a1 * a2 | (a)`; `b ::= a1 = a2 | a1 > a2 | b1 ∨ b2 | ¬b | (b)`;
`n ::= … -1 | 0 | 1 …`. Тобто обов'язкові зовнішній `begin … end` та `else`; від'ємні числа — числові
константи (`-1`), а не унарний мінус. `∨` і `¬` можна писати й як `or`, `not`.

**Розширення SIPL-ext** (частина 2 граматики) вмикаються лише прапорцем `--ext` (у бібліотеці —
`extensions=True`). Без прапорця кожне з них — синтаксична помилка `SYN-EXTENSION` з точною позицією:

| Розширення | Приклад |
|------------|---------|
| програма без зовнішнього `begin/end` | `X := 1; Y := 2` |
| `if` без `else` (= `else skip`) | `if X > 0 then Y := 1` |
| `div`, `mod` (ціле, округлення до −∞) | `X div 2` |
| унарний мінус перед не-числом | `-X` |
| `<`, `<=`, `>=`, `<>`, `!=` | `X <= Y` |
| `and`; `true`, `false` | `X > 0 and Y > 0` |

## Лексика
Ключові слова (регістрочутливі): `begin end if then else while do skip and or not true false div mod`.
Ідентифікатор: `[A-Za-z_][A-Za-z0-9_]*`. Число: ціле (перед ним може стояти `-`, див. вище). Оператори:
`:= ; + - * ( ) = > ∨ ¬` (+ `< <= >= <> !=` у SIPL-ext). Коментарі `// ...` та `/* ... */` — лексична
зручність, у БНФ курсу їх немає.

## Синтаксичні особливості
`;` — роздільник (не термінатор): `X := 1;` перед `end` — помилка. Гілки `if` і тіло `while` — один оператор;
для кількох використовується `begin ... end`. `else` прив'язується до найближчого `if`.
Арифметичні та булеві вирази розділені: `X := 1 > 2` і `while X + 1 do ...` — помилки.

## Операційна семантика (інтерпретатор)
Стан — відображення змінних у цілі. `and`/`or` обчислюються ліниво. Помилки виконання (з `span`):
`RT-UNDEFINED-VAR`, `RT-DIV-ZERO`, `RT-STEP-LIMIT`, `RT-INFINITE-LOOP`.
Крок = виконання оператора `Assign/Skip/If/While` (послідовність і блок кроків не створюють).

## Діагностики синтаксису
`SYN-UNEXPECTED-CHAR`, `SYN-BAD-NUMBER`, `SYN-UNTERMINATED-COMMENT`, `SYN-EMPTY-PROGRAM`,
`SYN-UNEXPECTED-TOKEN`, `SYN-EXPECTED-EXPRESSION`, `SYN-EXPECTED-RELOP`, `SYN-UNBALANCED-END`,
`SYN-EXTENSION` (конструкція SIPL-ext без `--ext`).
Кожна має `SourceSpan` (зміщення, рядок і стовпець початку/кінця; рядки й стовпці з 1).

## Семантичні терми (нотація практикуму, практична робота 2)
Побудова — рекурсивна, за правилами `sem_P`, `sem_S`, `sem_A`, `sem_B`:

| SIPL | Терм | Правило курсу |
|------|------|---------------|
| `skip` | `id` | NS_Stm_skip |
| `x := a` | `AS_x(sem_A(a))` | NS_Stm_As |
| `S1; S2` | `sem_S(S1) · sem_S(S2)` (S1 виконується першим) | NS_Stm_Seq |
| `if b then S1 else S2` | `IF(sem_B(b), sem_S(S1), sem_S(S2))` | NS_Stm_If |
| `while b do S` | `WH(sem_B(b), sem_S(S))` | NS_Stm_Wh |
| `begin S end` | `sem_S(S)` | NS_Stm_BE |
| число `n` (у т.ч. `-1`) | `n` | NS_A_Num |
| змінна `x` | `x⇒` | NS_A_Var |
| `a1 + a2`, `a1 - a2`, `a1 * a2` | `S²(add, …)`, `S²(sub, …)`, `S²(mult, …)` | NS_A_Add/Sub/Mult |
| `a1 = a2`, `a1 > a2` | `S²(eq, …)`, `S²(gr, …)` | NS_B_eq, NS_B_gr |
| `b1 ∨ b2`, `¬b` | `S²(or, …)`, `S¹(neg, …)` | NS_B_or, NS_B_neg |

Дужки не дають окремих термів (NS_A_Par, NS_B_Par). Операції SIPL-ext, яких немає в практикумі, мають імена
іменами `div`, `mod`, `uminus` (унарний мінус не перед числом), `ne`, `ls`, `le`, `ge`, `and`;
`if` без `else` дає `IF(b, f, id)`.

Приклад із практикуму (x^y):
`AS_R(1) · WH(S²(gr, Y⇒, 0), AS_R(S²(mult, R⇒, X⇒)) · AS_Y(S²(sub, Y⇒, 1)))` — збігається з книгою
(тест `test_practicum_example_matches_the_book_exactly`); на `x=5, y=2` дає `R=25`, як у книзі.
ASCII-варіант (`--ascii`): `S2(gr, Y=>, 0)`, ` . ` замість `·`.

Формули обчислення (`sipl.semantics.RULES`, назви з практикуму): `AF_ID`, `AF_AS`, `AF_SEQ`, `AF_IF`
(`AF_IF_T`/`AF_IF_F` — два випадки), `AF_WH` (`AF_WH_T` — одна ітерація, `AF_WH_F` — вихід із циклу) та
правила невизначеності `AF_AS-⊥`, `AF_IF-⊥`, `AF_WH-⊥`. Результат — кінцевий стан або ⊥ трьох видів:
`error` (ділення на нуль, змінна без значення), `diverges` (цикл повернувся в попередній стан),
`limit` (вичерпано бюджет застосувань правил). Обчислювач працює лише з термами й не залежить від
інтерпретатора, тому використовується для перехресної перевірки (інваріант: однаковий результат).
